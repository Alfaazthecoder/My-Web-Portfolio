System Architecture

Alfaaz. Photographer & Developer

Based in Abu Dhabi, I explore the spaces where rigid urban transit systems and resilient botanical life intersect. This portfolio serves as an open-source visual log documenting urban ecosystems, engineered using hardware-accelerated frontend architectures (Glassmorphism, Claymorphism, and Neomorphism) to ensure high-fidelity delivery.

[01 / OPTICS]

Leveraging high-aperture manual optics (Nikon Z30) to separate crisp foreground botanical textures from dense structural backgrounds.

[02 / GRADING]

Balancing natural sunlight with clean digital contrasts. Every asset undergoes precise geometric perspective mapping.

[03 / FRONTEND]

Hand-crafted semantic structure deploying non-blocking CSS variables, fluid responsive grids, and native GPU layers.
